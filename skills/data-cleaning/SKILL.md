# AHK Data Cleaning

1. Identify dataset grain and business keys.
2. Profile columns, types, cardinality, missingness and duplicates.
3. Detect invalid dates, impossible values, inconsistent categories, whitespace/case problems, duplicate keys and referential-integrity failures.
4. Classify issues as safe-to-fix, business-rule dependent, or unresolved.
5. Apply deterministic transformations with an audit trail.
6. Preserve raw data when possible.
7. Validate row counts, uniqueness, ranges and relationships after cleaning.
8. Report what changed and what remains uncertain.

Never silently delete records or impute values without a defensible rule.
