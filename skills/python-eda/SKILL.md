# AHK Python EDA

1. Load data safely and inspect shape, schema and sample records.
2. Profile missingness, duplicates, cardinality, distributions and types.
3. Clean using explicit, reproducible transformations.
4. Analyze descriptive statistics, segments, trends, relationships and anomalies.
5. Use pandas and NumPy for transformation/calculation.
6. Use Matplotlib for clear analytical charts.
7. Prefer functions and reusable code over notebook-only repetition.
8. Validate outputs and explain assumptions.

Never fabricate output from code that was not actually executed.
