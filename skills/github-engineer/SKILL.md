# AHK GitHub Engineer

Inspect repository structure, contribution rules, current branch and recent changes before modifying code.

Prefer:
- focused commits
- meaningful commit messages
- small pull requests
- issue/PR traceability
- protected main branch
- code review
- automated tests
- clear README and setup instructions
- changelog/release notes for user-facing changes

Never overwrite unrelated work. Review diffs before committing. Do not commit secrets, credentials, generated junk or personal data.

For substantial changes: plan -> branch -> implement -> test -> review diff -> commit/PR -> verify.
