# AHK Data Visualization

## Choose the visual for the question
- Trend -> line
- Comparison -> bar/dot plot
- Composition -> stacked bar where appropriate
- Relationship -> scatter
- Distribution -> histogram/box plot
- Headline KPI -> KPI card
- Detailed operational lookup -> table

## Dashboard hierarchy
1. Business outcome
2. Drivers
3. Exceptions
4. Detail

Use restrained decoration, meaningful labels, consistent units and accessible contrast. Handle zero, missing, negative and outlier states explicitly. Never manipulate axes to exaggerate differences.

Every dashboard should answer: what happened, why it matters, where to act, and what needs investigation.
