# AHK Frontend Engineer

Before coding, inspect existing architecture, entry points, dependencies, routing, state, API contracts and build tooling.

## Engineering principles
- semantic HTML
- modular CSS
- progressive enhancement where practical
- responsive layouts
- accessible controls and keyboard navigation
- clear loading/error/empty states
- input validation
- safe API handling
- minimal duplication
- maintainable component boundaries

Preserve existing behavior unless a change is required. Avoid replacing entire files when a targeted change is safer.

After implementation, verify build, runtime behavior, console errors, responsive behavior and critical user flows.
