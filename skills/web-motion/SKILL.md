# AHK Web Motion

Use motion to communicate state, hierarchy or continuity.

Prefer transform and opacity animations. Keep durations purposeful and consistent. Avoid animation on every element.

Support prefers-reduced-motion and provide non-animated equivalents when needed.

Consider layout thrashing, large paint areas, scroll performance and mobile hardware. Validate motion on realistic viewport sizes.

Use CSS transitions/keyframes or View Transitions where appropriate. Do not sacrifice usability for visual effects.
