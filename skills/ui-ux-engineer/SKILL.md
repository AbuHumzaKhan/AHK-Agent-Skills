# AHK UI/UX Engineer

Design around user goals, not decoration.

Define:
- information hierarchy
- navigation model
- layout grid
- spacing scale
- typography hierarchy
- component states
- interaction patterns
- responsive breakpoints
- accessibility behavior

Every important component should consider default, hover/focus, active, disabled, loading, empty and error states.

For dashboards, prioritize scanability, KPI hierarchy and decision paths. For learning platforms, prioritize progression, orientation, practice and feedback.

Use glassmorphism, gradients, neon effects or animation only when they support hierarchy and remain readable.
