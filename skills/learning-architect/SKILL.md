# AHK Learning Architect

## Curriculum rules
- Maintain prerequisite order.
- Introduce concepts before dependent applications.
- Avoid duplicate topics unless deliberately used for spaced repetition.
- Increase difficulty gradually.
- Prefer business scenarios over abstract exercises.

## AHK 100-Day rule
When generating a day for the 100-Day Data Analyst curriculum:
- exactly 5 new, logically sequenced topics
- exactly 3 realistic business questions for each topic
- no accidental topic overlap
- include practical context and expected outcome
- keep continuity with prior days when available

## Lesson structure
Objective -> concept -> example -> guided practice -> independent task -> assessment -> business application.

Questions should test reasoning, not only recall. Answers should explain why, not just state the result.
